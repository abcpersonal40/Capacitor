PER-APP POLICY

App policy

Ask হলে call অপেক্ষা করবে; Allow/Block stored decision ভবিষ্যৎ call-এ স্বয়ংক্রিয় হবে। Ask বা Block করলে সংশ্লিষ্ট live subscription/resource revoke করা হয়।

Network mode

sandboxed = আগেভাগে সব remote request বন্ধ · hosts = শুধু approved host · full = পুরো ইন্টারনেট খোলা (HTTPS/WSS + ফর্ম)। Full mode-এ app-টা তার পাওয়া native data বাইরে পাঠাতে পারে — শুধু বিশ্বস্ত app-কে দিন। প্রতিটা request-এর হিসাব নিচে usage-এ দেখা যায়।

⚠️ FULL mode চালু: এই app সব HTTPS/WSS host-এ যেতে পারবে। Camera/files/location capability দিলে সেই data-ও বাইরে যেতে পারে।
